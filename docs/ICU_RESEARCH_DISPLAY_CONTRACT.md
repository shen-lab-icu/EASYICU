# ICU 数据库研究的计划、分析与图表交付

2026-09-09。九问是开发验收样本；目标是可迁移的 ICU 数据库自动化科研能力。
不按题号、病例答案、特定数据库列名或预期数值编写生产分支。九问通过也不能证明任意新研究都已支持。

## 文献依据与使用边界

已核对以下原文的研究设计、分析说明及表图内容。它们是设计参考，不是本项目结果的直接对照，也不授予本项目临床或发表许可。

- [JAMA 2017：脓毒症发生情况及趋势](https://jamanetwork.com/journals/jama/fullarticle/2654187)：特征表交代研究人群，图呈现器官功能异常与死亡，以及发生情况/死亡趋势。借鉴问题、分母、比较对象与展示之间的对应关系，不照搬其人群定义和缺失处理假设。
- [JAMA 2019：脓毒症临床分型](https://jamanetwork.com/journals/jama/fullarticle/2733996)：Table 2 以总人群及各分型为列，变量/水平为行；分型特征、稳定性/复现和结局比较分别提供证据。不会因为聚类图好看就把分型当作因果分组。
- [TRIPOD+AI，BMJ 2024](https://www.bmj.com/content/385/bmj-2023-078378)：预测研究须明确开发/验证过程和性能评估，包括区分度、校准及适用时的临床效用。该文件是报告规范，不是可直接执行的模型开发配方。
- [TARGET，BMJ 2025](https://www.bmj.com/content/390/bmj-2025-087179.long)：明确目标试验方案及其与观察数据的对应、目标效应、识别假设和敏感性分析。
- [RECORD，PLOS Medicine 2015](https://journals.plos.org/plosmedicine/article?id=10.1371/journal.pmed.1001885)：常规医疗数据研究应透明报告人群识别算法、代码、数据处理与选择过程。无法获得的信息必须明确标出。

## 所有研究共享的交付链

原问题和指定数据 → 研究类型与问题要求 → 完整计划 → 数据与方法执行 → 有来源的结果 → 合适的展示 → 原问题回答。

计划须明确：研究单位和人群、时间起点/观测窗口、暴露/分组/参照、结局及分母、主次分析、缺失处理、适用的效应与不确定性、诊断/敏感性分析，以及每项结果的输出和用途。原问题要求的结局必须贯穿全链；执行不可用时保留缺口，不由报告文字掩盖。

展示须说明要回答的问题和信息增量。总人数可以是正文或表头，不自动占用一张图；流程图要求真实的进入、排除与保留步骤，不能从最终 N 反推筛选过程。Table 1 以分组为列，以变量和分类水平为行，分母及缺失规则清楚。正文、表、图无需重复全部数字。不得为满足图数或图型多样性新增分析。

## 依研究类型复用已有能力

| 研究类型 | 计划及分析的检查重点 | 有信息价值的展示 |
|---|---|---|
| 描述、发生情况、结局比较 | 定义、研究单位、分母、缺失/未记录边界、分组结局 | 特征表；有分母的比例/分布及组间结局；存在真实选择步骤时才用流程图 |
| 关联研究 | 时间设计、调整集合、效应尺度、函数形式、缺失及敏感性分析 | 绝对结局背景、效应估计及区间、剂量反应或必要的敏感性比较 |
| 预测研究 | 预测时点、数据划分、特征可用时间、防泄漏、内部/外部验证 | 校准与区分度；适用时临床效用；模型和人群说明 |
| 生存研究 | 时间起点、事件/删失、风险集、模型假设及适用的 RMST | 生存/累计发生曲线与风险人数、估计区间；相关诊断 |
| 因果模拟 | 目标试验、时序对齐、混杂控制、重叠/平衡、识别假设 | 设计说明、平衡/重叠诊断、效应及敏感性分析 |
| 分型与轨迹 | 拟合变量、时间对齐、缺失、聚类数依据、稳定性、独立结局比较 | 组间特征表、特征/轨迹、稳定性及结局；避免因果解释 |

这是适用性检查，不是每题强制执行全部方法。调整原科学范围须沿用完整计划修订流程。

## 本轮已实现和仍须验证

- 共享 Table 1 展示按变量/分类/分组身份转置，保持原始统计值，拒绝重复/缺失单元格、分母冲突和比较统计量冲突。Web 与 PDF 复用同一模块。
- 单个分母图由核验后的源表投影为文字；原图和源账本保留。无法核验源表时停止投影，不推测数值。该变更不是补齐完整人群筛选流程的证据。
- 实际 Progressive Planner 和旧 Planner 共用研究与展示规则；文章图表策略复用相同规则。此前只修改未被调用的提示渲染函数不能影响真实规划。
- 报告修订的 Web 图册/PDF 使用相同图选择、上下文和表格规则；PDF 参考文献只保留实际引用，按首次引用排序；当前 PDF 请求携带文件摘要。
- 后续验收：实际 Web 报告修订、预览/下载一致性与恢复；按研究类型检查需求保留和分析适配；九问顺序推进。新变量名、分组数量和源行顺序的定向测试是工程迁移检查，不能声称为额外真实研究通过。
- 现有执行器仍可保留单分母诊断图作为运行产物；报告读者层不再将其当作结果图。未来若要停止生成这种诊断文件，应由可选产物合同支持，不能伪造已承诺图产物完成。
- 科学结果、旧运行闸门和独立审阅要求不变；不提高通过题数，不创建后台自动化。
