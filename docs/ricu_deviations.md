# Deviations from ricu 0.6.3

EasyICU follows ricu 0.6.3 concept definitions unless a row below says
otherwise. Each row names the concept, the databases it reaches, what ricu
does, what EasyICU does, why, and the measured effect. Counts of 1–9 are
written as "<10". "Sample" means the 3,000-stay server sample of that database
used for the lead-r13 gates; "demo" means the public PhysioNet demo.

Per-commit details are in [extraction_changelog.md](extraction_changelog.md).

## Declared deviations

| Concept | Databases | ricu 0.6.3 | EasyICU | Why | Effect |
|---|---|---|---|---|---|
| `rass` label sources (and through it `ett_gcs`, `gcs`) | eICU | `nursecharting` value name `Sedation Score`, kept where the paired `Sedation Scale` row is `RASS` | The same source, plus two labels from "Other Vital Signs and Infusions": `RASS` and `SEDATION SCORE` (value name `Value`) | Both labels hold integers in −5..+4 with negatives present (extraction audit round 2, 2026-11-03). They are RASS scores charted under another label. | Through `ett_gcs` (RASS ≤ −3, 6 h windows) they open sedation windows ricu does not. eICU demo: 170 of the 176 remaining GCS cells that differ from ricu (64 `RASS`, 106 `SEDATION SCORE`). Pinned by `tests/core/test_eicu_rass_label_extension.py` (`e1d73cd7b`). |
| Pre-admission RASS windows (`ett_gcs`, `gcs`) | eICU | Keeps RASS rows recorded before unit admission and clamps their windows to hour 0 | The ICU episode window (`[-pre_admission_hours, upper]`) drops those rows before any GCS logic runs | Data-layer bound shared by every concept, not a GCS algorithm difference (supervisor ruling, 2026-11-06) | eICU demo: 6 GCS cells (3 TRUE windows starting 134–175 h before unit admission). The GCS components are identical on both sides. |
| Window expansion on AUMC `processitems` and SICdb `data_range` tables | AUMC, SICdb | `expand()` covers start hour through `floor(start + dur)` inclusive | These windows stay half-open (end hour excluded) this release | Not yet moved to the shared inclusive owner (`concept/window_expansion.py`); post-release backlog #13f | Not measured this release. |
| ICU episode bound (every concept with an episode clip) | All | Clips on the raw comparison of the derived hour with the bound | Inclusive on both ends, decided with the threshold helpers: an event within `1e-6 × max(1, |bound|)` hours of the bound is kept (0.09 s at the 24 h pre-admission bound, 3.6 s at a 1,000 h bound, 31.6 s at the 366-day fallback). One rule in pandas and SQL (`utils/icu_window.outside_episode`, `IcuWindowSql`). | The event hour and the bound are both derived (offset ÷ 60 or ÷ 3,600; discharge + 24 h), so an event charted exactly on the bound could land an ulp past it and be dropped (`f565a0db9`). | eICU demo: 2 cells (one glucose row at discharge + 1,440 min; one nicardipine cell at a bound hour). SICdb sample: extra rows exactly at the bound hour in chemistry, hematology, other_scores and renal (<10 each), and the SOFA grids extend to that hour (sofa1 26 rows, sofa2 50 rows, <10 stays). eICU sample: vitals and medications <10 rows each. |
| `systemic_intake`, `total_input_ml` and fluid balances (same-time rates) | eICU | Order of same-time rows is left to the input; the last row delivered owns the following segment | Same-time rows on one channel are ordered by rate; the largest rate owns the segment, smaller ones get duration 0 | Makes the result independent of batch size, bucket layout and thread count (`1962535eb`; pinned by `43cbe4aca`) | 0 changed stay-hours: demo 0 of 60,510; sample 0 of 95,864; full eICU 0 of 6,676,112 (6,192 rate rows in 75 stays, 0 same-time conflicting groups). |
| Creatinine, bilirubin, direct bilirubin and urea unit factors | AUMC, HiRID, SICdb, community sources | Rounded factors (creatinine 0.011309 AUMC / 0.011312 HiRID; bilirubin 0.058467; urea 2.8; SICdb urea 0.467) | Exact factors: 1/88.4, 1/17.1, 28.02/10, 28.02/60.06 | ricu's factors bias the converted value by about 1e-4, beyond the threshold tolerance, so boundary values were classed one SOFA level low (`c747d1900`) | Values that change class at their recorded precision: creatinine 442 µmol/L (SOFA-1 renal 3 → 4; AUMC, HiRID), HiRID creatinine 176.8, 309.4, 353.6 µmol/L, and bilirubin 34.2, 102.6, 205.2 µmol/L (SOFA-1 liver). Other converted values shift by at most 1e-3 relative. Full-cohort counts: errata block of each database's formal 0.2.0 `RUN_RECEIPT`. |
| `urine24` and the urine coverage rules | All | `fill_gaps` over the hourly grid; an uncharted hour counts as 0; NA below `min_steps` (12 h); no gap limit | An uncharted hour is missing; a record is spread back to the previous one over at most 12 h (exact, with the 12e-6 h tolerance); 18 covered hours needed, scaled by 24 / covered hours | Round-4 ruling R4-001 (`ade4802d7`), extended to KDIGO and SOFA-2 (RU-01/02/09); the exact-gap comparison is `d14e628ba` | MIMIC-IV sample, one stay: 35 hourly values kept that the float64 raw path had dropped. Full-cohort counts: formal `RUN_RECEIPT` errata. |
| `vaso60` (`*60` concepts) | Databases whose rate rows carry an infusion id: MIMIC-III (`linkorderid`), MIMIC-IV (`orderid`), HiRID (`infusionid`) | Expands each infusion once in its item callback; `vaso60` carries nothing forward | Repeats the per-infusion minute expansion, for rows that carry an infusion id only (`infusionid`, `orderid` or `linkorderid`) | Decided per row since `cc20f06a3`; deciding it per column made MIMIC-III depend on batch composition | MIMIC-III 3,000-stay sample (batch 1,000 vs one shot, before the fix): `epi60` in 16 stays, SOFA cardiovascular in 2. CareVue sample: byte-identical before and after. Full-cohort counts: formal `RUN_RECEIPT` errata. |
| Hospital discharge type, follow-up category, `TimeOfStay`, new items | SICdb 1.0.8 | ricu 0.6.3 reads SICdb 1.0.6 codes (2026 Survived / 2028 Deceased) | Codes read by their `d_references` label; an empty survivor follow-up category rebuilt from the admission year (2013–2020: one year; 2021: six months; otherwise unknown, NA and flagged, recorded deaths included); `TimeOfStay` as published; RASS 3123 and O₂ flow 3144 mapped | 1.0.8 renumbered the discharge types and leaves the category empty for survivors. With the 1.0.6 codes every 1.0.8 outcome was unknown. The category rule is a regularity in the data, not a documented rule: in the 27,350 cases common to both releases it is decided entirely by admission year (2021: 3,142 cases, all six months; 2013–2020: 24,208, all one year), and all 5,088 1.0.8 deaths with a category follow it. | On the same 1.0.6 data: no value change. Across releases: see the SICdb 1.0.8 changelog entry. |

## Aligned with ricu this release

These were deviations before lead-r13 and now match ricu 0.6.3. The
expected values come from ricu 0.6.3 itself (Rscript on the public demos or
on synthetic tables).

| Concept | Databases | ricu 0.6.3 | EasyICU before | EasyICU now | Effect |
|---|---|---|---|---|---|
| `gcs` sedation marking from `ett_gcs` | eICU | Sedated hours from the inclusive hourly grid of TRUE `ett_gcs` windows, in the window's unit | Read the 360-minute windows as hours, so each window marked up to 15 days | ricu's grid, in the declared unit (`80b1cb964`, `432ddaf3c`) | eICU demo vs ricu: differing GCS cells 1,860 → 176. eICU sample: GCS 3,899 cells (all 15 → measured) in 135 stays; SOFA-1 13,404 and SOFA-2 13,440 rows (CNS only). Other databases: 0 GCS cells. |
| `ett_gcs` published grid | All | `expand(aggregate = "any")`: start hour through `floor(start + dur)` inclusive; FALSE windows keep their duration | Half-open expansion; FALSE windows had zero duration; module exports published start hours only | One hourly boolean column with ricu's grid for the public API and exports (`e70102c94`) | eICU demo export TRUE/FALSE hours 1,808/10,944 → 4,485/27,675. MIIV sample TRUE hours 25,335 → 24,753. eICU sample: 5,549 respiratory rows added (ett_gcs only). |
| Windows that close before admission | All with `ett_gcs` windows | `expand()`: `end < 0` → 0 | Window stopped before hour 0 | Extended to hour 0 (`f9b45386c`) | MIMIC-III sample +117 TRUE hours (97 stays); CareVue sample +236 TRUE hours (192 stays), with GCS <10 cells, SOFA-1 and SOFA-2 28 rows each; AUMC sample 54 cells. All at hour 0 or earlier. |
| `ett_gcs` from point tables (no duration) | SICdb, AUMC | `gcs` expands the airway table only when it is a window table | Point rows were expanded with duration 0 and clamped to hour 0, and pre-admission points were spread up to hour 0 | Each point stays in its own floored hour, merged with `any`; FALSE and the boolean type kept (`942bfcbfb`) | SICdb sample: 3 cells TRUE → NA (3 stays, hour 0). AUMC sample: 54 cells (52 FALSE → NA, 2 TRUE → NA) in 53 stays, at hour 0 except one pre-admission hour. GCS, SOFA and Sepsis-3 unchanged. |
| Window with a missing duration | All | `expand()` drops it (`rm_na`) | Published as a one-hour exposure | Dropped; an explicit zero-length window is still one cell (`3e23c65d4`) | No current source is known to emit such rows; demos unchanged. |
| eICU dextrose infusion duration (`dex`) | eICU | `dur_var` is `interval(x)`, the requested load interval (1 h) | Smallest positive offset gap pooled across the batch | The requested load interval (`d9424b274`) | eICU sample: 1 cell (dex cells 21 → 22, <10 stays); other modules byte-identical. |
| Out-of-bounds values | All | Dropped per row against the concept's `min`/`max` | Dropped, except that a read with ≥ 100 values and none in bounds kept them (the SQL loader retried without bounds; an out-of-bounds median skipped the bounds). The lead-r13 candidate refused such reads instead (`0aa5a8185`). | TODO(r13bounds): line follows when the r13bounds branch merges | TODO(r13bounds) |
