Writer contract:

EVIDENCE-BINDING GATE — READ THIS FIRST:
A downstream CriticAgent inspects the finished manuscript. The run is
marked `evidence_complete=False` and downgrades to AO (analysis_only,
not manuscript_ready) the moment a single result-like sentence in
Methods, Results, Discussion, or Abstract lacks an inline
`{evidence:<id>}` token, even if the prose is true. This is a hard,
deterministic gate. There is no soft margin. Therefore:
  * Write the Results paragraph by listing the evidence ids you have
    AVAILABLE first, then writing one sentence per id you cite.
  * If a numeric claim has no matching evidence id in the available
    list, DELETE the sentence entirely. Do NOT paraphrase it, do NOT
    hedge it ("approximately"), do NOT write a placeholder.
  * Sentences that begin with phrases like "Overall,", "In summary,",
    "Notably,", "The cohort was...", "Mortality was...", "We found...",
    or any past-tense empirical statement are result-like and trip the
    gate unless followed by `{evidence:<id>}`.
  * Audit the final draft before returning: every sentence that
    contains a number, a comparison, or a clinical effect-direction
    word MUST include `{evidence:<id>}` somewhere in the same
    sentence. If you cannot satisfy this, drop the sentence.
  * This rule applies to every manuscript section, not only Results.
    Background, Introduction, Methods, Discussion, and Limitations
    sentences that mention a cohort, variable, database, model,
    mortality/outcome, association, missingness, robustness/sensitivity,
    performance, comparison, or numeric value must cite a valid evidence
    id in the same sentence. Use literature ids for literature context;
    use research-context / plan / cohort ids for design and variable
    context. If there is no suitable id, delete the sentence.

- Write a full manuscript in restrained clinical-paper prose.
- Make the title a neutral descriptive noun phrase. Do not put
  quantitative results, effect-direction language, or verdict words
  like "finds", "shows", or "associated" into the title.
- Discussion is REQUIRED and should be substantive: 5 paragraphs total,
  with interpretation, comparison to prior literature, plausible
  mechanisms stated cautiously, clinical implications/limits, and a
  reproducibility / evidence-traceability paragraph.
- Prefer short factual sentences, past tense in Results, and plain
  manuscript prose over meta-commentary.
- Abstract structure: one sentence on question/cohort, one sentence on
  analysis approach, one sentence on the primary numeric finding, one
  sentence on the main caveat when a validator raised a real warning.
  Every abstract sentence must carry an evidence id because every
  abstract sentence is interpreted as manuscript-facing.
- Introduction structure: 4-5 paragraphs, each carrying a distinct job
  (importance, prior evidence, uncertainty, gap, objective/hypothesis).
  Do not compress the introduction into a two-sentence stub.
- Results structure: cohort anchor first, primary association second,
  then one short audit/robustness sentence if the digest supports it.
- Only cite `table_one`, `outcome_rate`, or `primary_association` when
  those ids actually exist in the available evidence list. If an alias
  is absent, do not write a placeholder sentence around it.
- For prediction-model tasks, treat AUROC, Brier score, calibration,
  split strategy, and baseline prevalence as the primary results. Do
  not invent odds ratios or "significant predictor" prose unless a
  coefficient / effect table is explicitly present in the evidence ids.
- If no `table_one` alias is available, anchor cohort size to
  `research_context` or the model-performance step summary instead of
  writing "Table 1".
- If no `outcome_rate` alias is available for a prediction task, use
  baseline prevalence from `model_performance`,
  `prediction_performance`, or the prediction step summary.
- When a baseline number is unavailable, cite Table 1 in prose instead
  of writing `[TBD]`, leaving a blank, or inventing a value.
- Do not write sentences about the absence of an estimate, a missing
  effect size, or other pipeline limitations unless those exact facts
  are anchored to a registered evidence item. If a fact is unavailable,
  omit that sentence instead of narrating the absence.
- Do not write machine-facing phrases such as `warning: see manifest`,
  `the primary analysis reveals`, `data integrity`, or similar pipeline
  narration. Translate validator output into ordinary manuscript prose.
- Every numeric claim in Methods or Results must be either spelled
  out in words ("the cohort comprised X stays") with X immediately
  followed by an {evidence:<id>} placeholder, OR phrased as
  "see {evidence:<id>}".
- Sentences without an evidence id will be removed by the post-processor.
- Do not invent confidence intervals, p-values, or hazard ratios.
