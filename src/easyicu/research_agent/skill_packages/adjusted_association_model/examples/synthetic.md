# Synthetic example

Run `python -m easyicu.research_agent.skill_packages.adjusted_association_model --example --out ./reference_output`.
The command writes `example_cohort.parquet` and `spec.json` before running
`load_cohort` → `run_analysis` → `generate_all_plots` → `export_all`.
All values are generated by the package's fixed NumPy seed; none are patient data.
Inspect the result tables and manifest. Supply a reviewed JSON spec with
`--cohort` to analyze a different prepared cohort with the same host rules.
