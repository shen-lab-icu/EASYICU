# 固定 Landmark 关联研究

## 用途

完整的 landmark 研究：在固定时间点仍在院的患者中比较不同暴露分组的结局，避免不死时间偏倚。

## 何时使用

适合回答此类问题：
入 ICU 满一天仍在院的患者中，早期乳酸分组是否与此后的院内死亡相关？

## 何时不适用

- 暴露在所选时间点之后仍在变化 → 随时间变化暴露的生存研究
- 问题要求估计治疗的因果效应 → 目标试验模拟（因果推断）

## 工作原理

在同一固定时间点仍存活且仍在观察中的患者之间开始比较。只用此前获得的测量确定暴露分组。暴露不明者单独报告，估计仅适用于该时间点仍符合条件的人群。

## 计划将提出哪些内容供您审阅

计划将提出时间零点、固定时间点及纳入条件、暴露时间窗与分组、参照组、结局观察期限、协变量及重复住院处理；您在运行前一次审阅。Copilot 处理常规配置并呈现完整计划。
输入：获准使用的队列，含患者及住院标识、所需测量、单位和时间戳，以及分析所用的结局与随访信息。

## 步骤与检查

1. **队列描述与 Table 1**. 系统检查: 分母所用人数; 哪些测量可用; 人数与频率是否一致.
   - 基线特征表（Table 1）
2. **缺失与测量审计**. 系统检查: 分母所用人数; 哪些测量可用; 人数与频率是否一致.
   - 缺失与完整性审计
   - 缺失数据与完整案例敏感性
3. **暴露与结局分布**. 系统检查: 暴露与结局分组是否覆盖全部患者; 区间计算是否考虑重复观察; 解释是否保持描述性.
4. **固定 Landmark 关联研究**. 系统检查: 固定时间点的纳入条件和观察机会; 记录的变量编码; 拟合模型是否与审阅后的模型一致; 估计值与区间是否一致.
   - 调整后关联模型

## 常见停止原因

- **分析数据与审阅时的版本不同。** 请 Copilot 更新数据记录并准备修订后的计划供审阅。
- **提供的表格与计划所需列不一致。** 重新运行前，审阅建议修正的数据提取方案或变量清单。
- **计划遗漏了问题中的一部分。** 审阅补上该比较的计划，或审阅明确缩小问题范围后的计划。
- **当前计划无法支持所请求的分析。** 审阅说明的限制及建议改用的研究方法或数据方案，再决定是否继续。
- **无法读取已审阅问题的记录。** 请 Copilot 重新准备完整计划供审阅。
